# 運用コスト試算 — EnglishLearnApp Web版

**作成日**: 2026-03-20
**対象**: React SPA (S3 + CloudFront) + VOICEVOX Lambda (既存共有) + OpenAI API (ユーザー負担)
**前提**: 個人利用〜小規模（月間アクティブユーザー 1〜10名）

---

## 1. コスト前提条件

| 項目 | 想定値 | 根拠 |
|------|--------|------|
| 月間アクティブユーザー | 5名 | 個人利用想定 |
| 月間 TTS リクエスト | 5,000回 | 5名 × 1,000回/月 |
| 平均音声サイズ | 50KB | 短文英語・日本語文 |
| 月間 S3 配信データ量 | 10GB | SPA (2MB) × 5,000 PV |
| CloudFront キャッシュヒット率 | 95% | 静的アセット主体 |
| Lambda 実行時間 | 5秒/リクエスト | VOICEVOX エンジン |
| Lambda メモリ | 2,048MB | 既存 iOS版設定と同一 |

> **OpenAI API 費用はユーザー自身の API キーで支払う**ため、インフラコストに含まない。

## 5. スケール別コスト比較

| ユーザー規模 | 月間TTS | Lambda/月 | CloudFront/月 | AWS合計/月 |
|------------|---------|----------|--------------|-----------|
| 小（5名） | 5,000回 | ¥842 | ¥190 | **¥1,038** |
| 中（50名） | 50,000回 | ¥8,420 | ¥1,900 | **¥10,325** |
| 大（200名） | 200,000回 | ¥33,680 | ¥7,600 | **¥41,285** |

> 中規模以上になった場合は Provisioned Concurrency（¥52,000/月〜）と S3 音声キャッシュ（Lambda→S3 に音声保存し Lambda の重複実行を削減）の導入を推奨。

---

## 6. コスト最適化施策

| 施策 | 削減効果 | 実施タイミング |
|------|---------|-------------|
| IndexedDB 音声キャッシュ | Lambda 再実行を削減（推定 60〜80%削減） | フェーズ1 |
| CloudFront キャッシュポリシー最適化 | 転送コスト削減 | フェーズ1 |
| S3 音声キャッシュ（Lambda側） | 同一テキストの Lambda 再実行を排除 | フェーズ2 |
| Provisioned Concurrency | コールドスタート解消（費用 +¥52,000/月、50名以上で検討） | フェーズ2以降 |
