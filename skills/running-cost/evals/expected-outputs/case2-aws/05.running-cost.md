## 6. コスト最適化の提案（Web版追加）

| 施策 | 削減効果 | 優先度 | 備考 |
|------|---------|--------|------|
| S3 音声キャッシュの実装 | Lambda 呼び出し 30〜50% 削減 | 高 | iOS版と同様 |
| **CloudFront キャッシュポリシー最適化** | SPA 配信コスト削減 | 中 | 静的ファイルに長期TTL設定 |
| **Lambda 関数 URL への移行（API GW 代替）** | API Gateway コスト削減（ほぼ¥0） | 低 | WAF・細かいレートリミットが不要な場合 |
| ECS Fargate への移行（本番規模） | Provisioned Concurrency より安価 | 高 | 月1,000件以上で Fargate が有利 |
| Lambda ARM64（Graviton2）移行 | 約20%削減 | 中 | VOICEVOX x86_64との互換性要確認 |
