# 運用コスト試算 — VOICEVOX TTS インフラ Web版対応 (AWS)

**作成日**: 2026-03-20
**対象**: iOS版共有 VOICEVOX Lambda + Web版追加 CloudFront + S3
**前提**: 個人利用〜小規模（月間アクティブユーザー 1〜10名）

---

## 1. コスト前提条件

| 項目 | 想定値 | 根拠 |
|------|--------|------|
| 月間 TTS リクエスト（Web版分） | 5,000回 | 5名 × 1,000回/月 |
| Lambda 実行時間 | 5秒/リクエスト | VOICEVOX Engine 実測値 |
| Lambda メモリ | 2,048MB | iOS版設定と同一 |
| React SPA サイズ | 2MB | Vite ビルド成果物 (gzip後 ~600KB) |
| 月間 SPA ページビュー | 5,000PV | 5名 × 1,000PV/月 |
| CloudFront キャッシュヒット率 | 95% | 静的アセット主体 |
