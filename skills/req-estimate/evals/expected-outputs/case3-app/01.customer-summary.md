# 要件確認・対応方針 — EnglishLearnApp Web版

## 対応可否
**対応可能**

iOS版で実績のある設計・インフラをそのままWeb版に転用できます。既存の VOICEVOX Lambda エンドポイントを再利用し、React SPA を S3 + CloudFront でホスティングするアーキテクチャで、追加バックエンドサーバーなしに全機能を実現できます。

---

## ご要件の理解

- **AI例文生成**: 英単語を入力すると OpenAI が例文・日本語訳・発音記号を自動生成
- **TTS音声**: iOS版と同じ VOICEVOX Lambda エンドポイントを使い「ずんだもん音声」をブラウザで再生
- **発音チェック**: マイクで録音し、Web Speech API で正誤判定（Chrome / Edge 推奨）
- **連続再生**: バイリンガル（英→日→英）または英語のみモードで複数例文を順番再生
- **単語管理**: 追加・編集・アーカイブ・ゴミ箱（10日間復元可能）+ JSON エクスポート/インポート
- **データ永続化**: IndexedDB によるブラウザローカルストレージ（iOS版の FileManager JSON 相当）

## リスク・注意点

- **Web Speech API の制限**: 発音チェック・日本語TTS フォールバックは Chrome / Edge のみ対応。Safari ユーザーは一部機能が使えません
- **VOICEVOX Lambda のコールドスタート**: 初回リクエスト時に最大30秒の遅延が発生します（iOS版と同様）
- **APIキーのブラウザ保管**: OpenAI APIキーを localStorage に保存するため、共有PCなどでの漏洩リスクがあります
- **CORS 設定**: 既存 Lambda の API Gateway に Web版ドメインの CORS 許可設定を追加する必要があります（+0.5人日）
