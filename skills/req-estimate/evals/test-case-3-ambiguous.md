# AIチャットボット開発 要件

## やりたいこと
社内の問い合わせ対応をAIチャットボットで自動化したい。
よくある質問への回答と、複雑な質問は担当者へエスカレーションする仕組み。

## 詳細
- SlackかWebサイトに埋め込む形で（どちらがいいか相談したい）
- 社内FAQドキュメント（Word, PDF で数十ファイル）を学習させたい
- 「AIが答えられない場合は人間にパス」したい
- 回答精度はできるだけ高くしたい
- 管理者がFAQを更新できるようにしたい

## 技術面での希望
- できればChatGPTを使いたい
- セキュリティが心配（社内情報が外部に漏れないか）
- スマホでも使えるようにしたい
