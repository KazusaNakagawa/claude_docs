## システム概要

シンプルなECサイト。React + Python (FastAPI) + AWS 構成。

## 機能要件

- ユーザー登録・ログイン（メールアドレス + パスワード、Googleソーシャルログイン）
- 商品一覧・詳細表示（カテゴリ絞り込み・フリーワード検索）
- カート・注文（複数商品、数量指定）
- 注文履歴の閲覧
- 管理画面（商品・在庫管理、注文ステータス更新）

## 非機能要件

- 月間アクティブユーザー: 約1,000人
- 商品数: 〜500件
- 同時接続: 最大50セッション
