## 2. AWSインフラコスト明細

**想定規模**: 月間アクティブユーザー 100〜500 名

| サービス | 月間利用量（推定） | 月額（目安） |
|---------|-----------------|------------|
| CloudFront | 50GB 配信 × $0.009/GB + 10万req × $0.0000085/req | ¥675 |
| S3（フロントエンド静的ファイル） | 100MB ストレージ + PUT/GET | ¥15 |
| API Gateway（HTTP API） | 10万リクエスト/月 × $1/100万req | ¥15 |
| Lambda（FastAPI / Mangum） | 10万req × 1秒 × 512MB = 51,200 GB秒（Free Tier 超過分: 0 GB秒） | ¥0 |
| RDS PostgreSQL t3.medium | $0.068/時間 × 720時間 | ¥7,344 |
| Cognito | 月間 100〜500 MAU（Free Tier 5万MAU 以内） | ¥0 |
| Secrets Manager | 3シークレット × $0.40 + API呼び出し | ¥195 |
| CloudWatch Logs | Lambda + RDS ログ ~2GB/月 × $0.76/GB | ¥228 |
| CloudWatch アラーム | 8アラーム × $0.10 | ¥12 |
| VOICEVOX Lambda（TTS 分） | iOS版と共通（月1万リクエスト相当） | ¥500 |
| NAT Gateway（Lambda → RDS 通信） | $0.045/時間 × 720 = $32.4 | ¥4,860 |
| ECR（VOICEVOX コンテナ） | 3GB × $0.10/GB | ¥45 |
| **AWSインフラ合計** | | **¥13,889 ≈ ¥12,000〜14,000/月** |

### 算出根拠

- **RDS**: Web版の最大コスト項目。t3.medium（$0.068/時間）が月額の約50%を占める。アクセスが少ない時間帯に自動停止する Aurora Serverless v2 への移行で削減できる（ただし接続オーバーヘッドに注意）
- **NAT Gateway**: Lambda から VPC 内の RDS へ接続するために必要。月額 ¥4,860 は固定コストとして計上
- **Cognito**: 月間 50,000 MAU まで無料。MVP 段階では事実上無料

## 6. コスト最適化の提案

| 施策 | 削減効果 | 優先度 | 備考 |
|------|---------|--------|------|
| Aurora Serverless v2 への移行（RDS の代替） | アイドル時間が長ければ 30〜50% 削減 | 高 | 利用者が少ない夜間に自動スケールダウン |
| Lambda ARM64（Graviton2）移行（FastAPI） | 約20%削減 | 高 | Python は ARM64 互換問題なし |
| NAT Gateway → VPC エンドポイント | NAT Gateway コスト削減 | 中 | Secrets Manager・S3 は VPC エンドポイント経由でアクセス可能 |
| S3 Intelligent-Tiering（ログアーカイブ） | 微小 | 低 | |
| Reserved Instance（RDS t3.medium） | 最大 40% 割引 | 中 | 1年以上継続運用が確定した時点で適用 |
| Cognito 代替（self-hosted Auth.js） | Cognito 費用削減（MAU 増加後） | 低 | 複雑化リスクあり、MAU 50,000 超えてから検討 |
